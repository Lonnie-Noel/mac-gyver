# 0.1.0 구현 및 검증 기록

검증일: 2026-09-15. 개발 환경: Linux x86_64, Python 3.12.14, PySide6 6.11.2, pytest 9.1.1.

계획서의 첫 버전 기능을 소스로 구현했습니다. 실제 아이폰을 사용하는 완료 기준은 아래의 실기기 확인이 남아 있습니다.

## 구현된 기능

- Appium/XCUITest 연결 설정·환경 진단·기기 검색과 스크린샷 미리보기
- 맥 미리보기의 탭·더블탭·길게 누르기·스와이프·드래그·핀치·회전 입력과 기록
- 누름·이동·끝점 유지·후 대기, 선택적인 입력 사이 대기 기록
- 단계 추가·수정·복제·삭제·순서 변경·반복 그룹, JSON 편집·저장·열기
- 요소 선택·조건 대기·요소 검사·이미지 영역 검사·스크린샷
- 시작 화면 검사, 화면 크기·방향 및 연결한 대상 앱 확인
- 준비 단계·반복 실행, 일시정지·재개·중단, 실행 단계 강조
- 기록 실패 표시, 자동 제스처 재시도 금지, 직렬 실행
- JSON·HTML·PNG 보고서와 별도로 표시되는 오프라인 모의 기기
- 실행용 `.command`, CLI, macOS `.app` 빌드 스크립트

## 자동 검증

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

**86개 통과.** 검사 대상은 다음과 같습니다.

| 영역 | 확인한 동작 |
| --- | --- |
| 모델·파일 | 잘못된 숫자·좌표·반복·경로 거부, JSON 왕복, 기준 이미지와 함께 다른 폴더로 이동 |
| 제스처 변환 | 스크린샷 픽셀과 논리 좌표 구분, W3C 이동 시간, 두 포인터 동기화, 각도 단위 |
| 실행 엔진 | 준비 단계 1회, 반복, 조건 제한 시간, 일시정지·중단, 시작 전 중단, 검사 판정 |
| 오류 | 연결·명령 실패, 알림창, 화면 방향 및 대상 앱 불일치, 자동 재시도 없음 |
| Qt 화면 | 실제 마우스 이벤트로 기록→저장→열기→재생, 여백 클릭 무시, 중복 명령 차단 |
| 편집기 | 가져온 유효한 제스처 설정을 열고 저장할 때 값 보존 |
| 결과 | HTML 이스케이프, 캡처 실패와 원래 오류 구분, 모의 실행 표시 |

Appium 통신 테스트는 가짜 드라이버를 사용합니다. Qt 통합 테스트는 모의 기기를 사용합니다. 이 테스트 개수는 실제 아이폰에서 확인한 제스처 수가 아닙니다.

## 실행·배포 경로 확인

- `bash Start.command --version`: 최초 의존성 설치·editable 패키지 설치 후 `0.1.0` 출력. 재실행 시 재설치 없이 동작.
- 프로젝트 밖의 작업 폴더에서 설치된 모듈의 CLI 실행 확인.
- `--demo --run examples/demo_roundtrip.json`: 사진 왕복 3회, 23개 실행 결과, 12개 검사 통과, PNG 3장과 JSON·HTML 생성. 종료 코드 0, `simulated: true`.
- Python wheel 빌드 성공. GUI·엔진·백엔드·CLI 진입점 포함 확인.
- 한국어 글꼴을 적용한 Qt 오프스크린 화면에서 입력 패널·단계 목록·미리보기·로그 배치 확인. macOS 기본 글꼴 렌더링 확인은 별도로 필요.
- 셸 스크립트 구문 및 경로에 공백이 있는 실행 경로 확인.

## 맥과 아이폰에서 남은 확인

1. 사용자의 macOS·Xcode·iOS 조합에서 WDA 서명과 USB 연결을 완료합니다.
2. 실제 사진 앱에서 테스트 사진 A→B→A를 기록하고, 요소 또는 기준 이미지 검사를 지정해 1회 재생합니다.
3. 실제 사진 앱의 현재 화면이 처리하는 확대·축소·회전·길게 누르기를 확인합니다.
4. 화면 방향 변경·예상치 못한 팝업·케이블 분리·실행 중 중단을 확인합니다.
5. 맥에서 `.app`을 빌드하고 실행·파일 저장·데모·실기기 연결을 확인합니다.

[설정 및 실기기 결과 기록표](SETUP_MAC.md#7-실기기-수동-검증-기록)를 사용하세요. `.app` 바이너리, 서명·공증, 실제 아이폰 성공 결과는 이 저장소에 포함하지 않았습니다.
