# mac-gyver

맥에 연결된 아이폰에서 터치 동작을 기록하고, 딜레이와 반복 횟수를 편집해 재생하는 데스크톱 테스트 도구.

**현재 상태: 구현 계획과 저장소 기본 구조를 준비한 단계입니다. 실행 가능한 앱은 아직 포함되어 있지 않습니다.**

## 목표 환경

- 맥 PC와 USB로 연결한 아이폰 1대.
- 아이폰 개발자 모드 활성화.
- Xcode, Appium, XCUITest Driver 및 서명된 WebDriverAgent.
- Python + PySide6 기반 한국어 데스크톱 UI.

실제 macOS·Xcode·iOS 조합을 확인한 뒤 의존성 버전을 고정합니다.

## 동작을 입력하는 방법

맥 앱에서 아이폰의 화면 미리보기를 보고 동작 도구를 선택합니다. 입력한 동작을 실제 아이폰에서 실행하면서 테스트 단계로 기록합니다.

| 동작 | 입력 방법 |
| --- | --- |
| 사진 선택 | 탭 도구로 미리보기의 사진 클릭 |
| 좌우 넘기기 | 스와이프 도구로 시작점부터 끝점까지 마우스 드래그 |
| 길게 누르기 | 위치와 누르는 시간 지정 |
| 확대·축소 | 대상과 배율·속도 지정 |
| 대기 | 단계 사이에 시간 또는 조건 대기 추가 |
| 반복 | 연속 구간 선택 후 횟수와 회차 사이 대기 지정 |

사용 흐름은 기록 시작, 동작 수행, 기록 종료, 시간·반복 구간 편집, 실행 순서입니다. 기록 대상은 맥 앱을 통해 입력한 명령입니다. 아이폰 본체에서 직접 수행한 손가락 동작의 수집은 첫 버전 범위에 포함하지 않습니다.

## 첫 검증 시나리오

사진 A 선택 → 1초 대기 → 300ms 동안 왼쪽 스와이프 → 1초 대기 → 300ms 동안 오른쪽 스와이프.

먼저 사진 A → B → A 전환을 실기기에서 확인하고, 왕복 구간을 20회 반복합니다. 명령 실행 완료와 화면 검사 통과는 구분해서 기록합니다. 시간 설정은 목표값이며, 명령 처리와 앱 반응으로 실제 시각에는 차이가 생길 수 있습니다.
