# 여기에 처리할 이미지를 넣으세요

1. 이 폴더에 JPG, JPEG, PNG, HEIC, HEIF, TIF 또는 TIFF 이미지를 넣습니다.
2. 사진 앱을 시스템 사진 보관함의 일반 보기 화면으로 열어 둡니다. 앨범 선택이나 ID 입력은 필요 없습니다.
3. 처음에는 상위 폴더의 **Mac 사진 자동화 1장 테스트.command**를 실행합니다.
4. 결과를 확인한 뒤 **Mac 사진 자동화 시작.command**로 이 폴더 전체를 처리합니다.

파일명 순으로 처리하며 하위 폴더, 동영상, 애니메이션, 심볼릭 링크는 처리하지 않습니다. 여러 프레임이 들어 있는 이미지는 중지 사유가 됩니다. 1장 테스트는 첫 파일 한 장만 가져옵니다.

이 폴더의 파일은 변경하지 않습니다. 사진 앱에 실행별 작업 앨범과 복사본을 만들며, 처리 후 복사본을 원본 상태로 복귀시킵니다. 작업 앨범은 사진 앱에 남아 있고 다음 실행 시 새로 만듭니다. iCloud 사진을 사용하면 복사본도 동기화될 수 있습니다.

결과는 상위 폴더의 `artifacts/photos-날짜시간/`에 저장됩니다. 이 폴더의 이미지는 Git에서 제외됩니다.
