# 여기에 처리할 이미지를 넣으세요

1. 이 폴더에 JPG, JPEG, PNG, HEIC, HEIF, TIF 또는 TIFF 이미지를 넣습니다.
2. 사진 앱을 시스템 사진 보관함의 일반 보기 화면으로 열어 둡니다. 앨범 선택이나 ID 입력은 필요 없습니다.
3. 처음에는 상위 폴더의 **Mac 사진 자동화 1장 테스트.command**를 실행합니다.
4. 결과를 확인한 뒤 **Mac 사진 자동화 이어하기.command** 또는 **Mac 사진 자동화 시작.command**로 같은 앨범의 남은 사진을 처리합니다.

파일명 순으로 처리하며 하위 폴더, 동영상, 애니메이션, 심볼릭 링크는 처리하지 않습니다. 여러 프레임이 들어 있는 이미지는 중지 사유가 됩니다. **1장 테스트도 폴더 전체를 한 번에 가져온 뒤, 다음 미처리 사진 한 장만 편집합니다.**

이 폴더의 파일은 변경하지 않습니다. 사진 앱에 작업 앨범과 복사본을 만들며, **작업 앨범과 편집 결과를 그대로 남깁니다.** 다음 실행은 같은 앨범에서 이어갑니다. 모두 처리하면 종료하며 다시 실행해도 복사본을 추가하지 않습니다. iCloud 사진을 사용하면 복사본과 편집도 동기화될 수 있습니다.

진행 중에는 입력 파일을 바꾸지 마세요. 입력을 교체하거나 새로 테스트하려면 상위 폴더의 터미널에서 `npm start -- --new-run`을 실행합니다. 새 앨범을 만들며 이전 작업 앨범은 보존합니다. 이어하기 기록은 상위 폴더의 `artifacts/input-batch.json`입니다.

결과는 상위 폴더의 `artifacts/photos-날짜시간/`에 저장됩니다. 이 폴더의 이미지는 Git에서 제외됩니다.
