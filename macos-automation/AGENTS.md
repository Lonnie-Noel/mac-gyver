# Mac 사진 자동화 작업 규칙

- 이 폴더는 Mac의 사진 앱을 직접 조작한다. 아이폰용 WDA/Appium과 별도다.
- 문서 수정, 빌드, 구문 검사 때문에 사진 앱을 조작하거나 앨범 전체 처리를 시작하지 않는다. 실기기/실사진 검증과 일괄 실행은 사용자가 지정한 작업 범위 안에서만 수행한다.
- 기존 대화에서 승인한 작업은 승인 범위를 유지한다. 이미 승인된 작업에 불필요하게 재확인을 요구하지 않는다.
- 기존 편집이 있는 사진은 건너뛴다. 원본으로 복귀는 이전 편집을 모두 지우므로 마지막 Reframe만 취소하는 수단으로 쓰지 않는다.
- 편집 저장 후 JPEG 내보내기와 검증을 마친 뒤 원본으로 복귀한다. 미완료 편집 기록을 지우거나 성공으로 간주하지 않는다. 복구할 때는 기록의 사진 식별자를 다시 확인한다.
- 사진 라이브러리 데이터베이스를 직접 수정하지 않는다. Photos UI/Apple Events/PhotoKit이 제공하는 동작만 사용한다.
- `artifacts/pending-edit.json`이 있으면 도우미 앱을 다시 빌드하지 않는다. 먼저 기존 앱으로 복구한다. 실행 중 자동 빌드하지 않는다.
- 앨범 ID와 사진 ID를 기준으로 작업한다. 시작 시 확정한 목록을 유지하며, 사진 앱과 시스템 사진 보관함의 식별자가 일치하지 않으면 중지한다.
- 권한 설정을 우회하거나 자동으로 보안 설정을 바꾸지 않는다. 사용자가 macOS 설정에서 도우미 앱에 필요한 권한을 부여한다.
- 사진, 캡처, 편집 기록, 개인 설정과 로그는 `artifacts/`, `config.json`, `logs/`에 두고 커밋하지 않는다.
- 소스/오프라인 검사와 실제 사진을 사용한 검증을 구분해 보고한다. 검증하지 않은 UI 흐름을 성공했다고 기록하지 않는다.
